What the columns mean

name: column suffix, the record column is EM01_<name>. 1 to 7 characters, a-z and 0-9. Keep the standard names (): the alarms, the daily report and the OED export look for them.
fc: 3 = holding registers, 4 = input registers. addr: 0-based address, 0x0018 or 24 (PLC number 40025 with fc 3 = 0x0018).
type: u16 s16 (one register), u32 s32 f32 (two registers, high word first), u32sw s32sw f32sw (low word first).
scale: raw value x scale = value in V, A, Hz, kW, kvar, kVA, kWh, kvarh (a meter in W needs 0.001).
ct: also multiplied by the logger's ct_mult (meters that give secondary values).
agg: minmax = mean + _min + _max columns, mean, last for energy counters.

How it reaches the logger: the logger asks for a new table every rcfg_check_m minutes (15 by default) or at once with the console command config. It checks the table, writes /config/registers.csv on its SD card (the previous file is kept as registers.bak) and restarts. The columns of that day's records change, so the platform starts a _2 day file.
