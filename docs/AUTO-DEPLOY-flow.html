Auto-deploy flow

You merge the release pull request on your phone. GitHub tags it once the tests pass, and within 5 minutes the VPS takes it by itself: backup, rebuild, health check, and back to the previous version if the check fails. No PC, no SSH.

  1. A cloud session opens the release pull request
  2. You merge it on GitHub (your only tap)
  3. CI tests it and pushes the tag vX.Y.Z
  4. The VPS pulls the tag and deploys it within 5 minutes
